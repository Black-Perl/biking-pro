Biking Pro für Android


App für Android für Fahrradfahrer.
Einfaches Mitschreiben der eigenen Fahrradtour inklusive Map auf dem lokalen Smartphone. Keine Cloud, keine Datenschleuder, keine Werbung!

Es können geplante Touren als .gpx-Dateien importiert und über die Map angezeigt werden, so ist Planung und Aufzeichnung auf einer Map sichtbar.
Absolvierte Touren sind unter "vergangene Fahrten" einsehbar und können als .gpx-Dateien exportiert werden.


English users:
App for Android for cyclists. Easy to write down your own bike tour including map on your local smartphone. No cloud, no data slingshots, no advertising! 
Planned tours can be imported as.gpx files and displayed via the map, so planning and recording 
is visible on a map. Completed tours can be viewed under "past trips" and can be exported as.gpx files.
